\# TechGadget Support Chatbot



This is a simple chatbot script written in Python. It simulates a basic customer support interaction.



\## 💻 How to Run in Jupyter Notebook



1\. Open Jupyter Notebook

2\. Navigate to the directory containing `chatbot.ipynb`

3\. Open the notebook file

4\. Run each cell using \*\*Shift + Enter\*\*



\## 🐍 Requirements



\- Python 3.x

\- Jupyter Notebook (Install with `pip install notebook`)



\## 🚀 Running as a Script



You can also run the chatbot in a terminal:

```bash

python chatbot.py
